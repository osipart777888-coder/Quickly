# Сбор компаний в Quickly

Откройте `http://localhost:8765/companies` или пункт **Сбор компаний** слева.

## Что работает без платных ключей

- Публичные страницы сайтов по введённым URL: главная и до трёх найденных страниц «Контакты», «О компании», «Реквизиты».
- Импорт CSV/TSV/XLSX с компаниями и корпоративными контактами; формат GeoLeadScraper.
- Импорт XML ЕГРЮЛ/ЕГРИП с элементами СвЮЛ/СвИП и основным/дополнительными ОКВЭД. Большие выгрузки нужно делить на файлы до 20 МБ и 10 000 организаций. Архивы и произвольные форматы XML не поддерживаются.
- База компаний, несколько email/телефонов, основной email, источники каждого значения, история запусков, поиск/фильтры, CSV/XLSX, согласия и отказы, передача в существующие контакты Quickly.

## Первый запуск

1. На вкладке **Новый сбор** оставьте **Сайты организаций**. Введите известные сайты, по одному URL в строке, либо выберите файл с компаниями.
2. Укажите основание права хранения и обработки, например свои сайты или разрешение владельца данных. Подтверждайте его только при наличии таких прав. Это не согласие на рекламу.
3. Укажите число компаний: 100 / 500 / 1 000 / 5 000 или собственное до 10 000. Отрасль используется для запроса к каталогам; точные ОКВЭД, численность и правовой статус фильтруют результаты по достоверно установленным полям.
4. Нажмите **Начать сбор**. Прогресс находится в **Истории запусков**. **Пауза** останавливает работу после текущего сетевого обращения, **Продолжить** возобновляет её, **Остановить** окончательно прекращает текущий запуск.
5. Нажмите **Просмотреть результаты**. На странице 50 компаний. Если включены точные фильтры, записи с неизвестными полями скрываются. Рубрики карт никогда не превращаются в ОКВЭД автоматически.
6. Нажмите название компании: откроются контакты, точные URL обнаружения, дата и источник каждого поля. Неоднозначные совпадения помечаются для проверки.

Задачи хранятся в PostgreSQL. После обычного перезапуска работа продолжается; незавершённый сетевой пакет можно повторить после истечения аренды до 5 минут. Пакет и обновление карточек фиксируются одной транзакцией. При восстановлении резервной копии активные сборы переводятся на паузу, автоматические email-отчёты выключаются.

## Файлы импорта

Обязательна колонка `name`, `title` или `Название`. Остальные необязательны:

```text
name,website,email,phones,inn,kpp,ogrn,city,region,okved_main,okved_extra,okved_as_of,active,employees,source_url
```

Несколько email/телефонов разделяйте точкой с запятой внутри CSV-поля в кавычках. В XLSX храните ИНН/ОГРН/КПП как текст, чтобы Excel не потерял ведущие нули. Невалидные реквизиты видны в ошибках запуска. Адреса `noreply`, шаблонные email и имена графических файлов отбрасываются.

GeoLeadScraper: изучены MIT-лицензия, `export.ts` и `DATA_EXPORT_FIELDS`. Поддерживаются `title`, `website`, `email`, `phone`, `phones`, `municipality`, `categories`, `place_id`, `maps_url`. Код скрейпера не заимствован. MIT-лицензия программы не даёт прав на данные карт: `maps_url` сохраняет исходную атрибуцию Яндекса/2ГИС, и их права хранения проверяются также при импорте.

## Источники и ключи

Вкладка **Источники и API → Настроить**. Ключи не возвращаются браузеру, шифруются существующим механизмом Quickly и включаются в защищаемую пользователем резервную копию. Пустое поле ключа при сохранении сохраняет прежнее значение.

| Источник | Реализация и необходимые настройки |
|---|---|
| Сайты | Готов. Нужны URL/файл с сайтами и подтверждение прав конкретного запуска. Чтение robots.txt, пауза, до 4 страниц на домен, без JS и отправки форм. |
| Яндекс Карты | Официальный HTTPS Search API с `results`/`skip`. Нужны API-ключ, договор с правом хранения в CRM и экспорта, название тарифа, стоимость запроса, предел расходов и числа запросов в сутки, явное разрешение платных запросов. |
| 2ГИС | Официальный Places API с `page`/`page_size`. Дополнительно нужен `region_id`; `rubric_id` необязателен. Контактные поля, ИНН и численность запрашиваются только при включённых отдельных разрешениях. |
| СПАРК | Подключаемый адаптер и экран доступа подготовлены. До получения WSDL и договорного описания методов — **Не подключён**. Несуществующие методы и доступ не имитируются. |
| ЕГРЮЛ/ЕГРИП | Импорт разрешённого официального XML/CSV/XLSX. Автоматическая общероссийская загрузка и обход сайта ФНС не выполняются. |

У платных источников бюджет списывается локально **до** сетевого запроса, включая запросы с сетевой ошибкой. Это ограничитель запросов, не биллинг: стоимость задайте по своему договору с учётом платных полей. При исчерпании бюджета задача приостанавливается; увеличьте разрешённый бюджет или продолжите на следующий день. Отключённые источники отражаются в истории, доступные продолжают работать.

Право экспорта проверяется заново перед каждым экспортом и передачей в Quickly. Поля из запрещённого источника не попадают в файл, даже если карточка объединена с разрешённым источником. Изначально запрещённые к хранению ответы API не запрашиваются и не сохраняются.

## Согласие и передача в рассылки

Найденный публичный email получает статус **Согласие неизвестно**. Импорт файла не подтверждает согласие.

1. В карточке нажмите **Согласие / отказ**.
2. Для подтверждения укажите конкретный email, рекламодателя (вашу компанию), проверяемое основание, ссылку/номер документа и дату получения согласия.
3. Выделите компании в результатах, выберите кампанию или **Только в базу контактов**, нажмите **Добавить в базу Quickly**.

Неоднозначные/исключённые компании, адреса без подтверждения, недействительные и отписавшиеся получатели не передаются. В существующую кампанию участник добавляется **на паузе**: проверьте шаблон и настройки перед возобновлением. Во время реальной отправки согласие адреса проверяется повторно, чтобы отзыв после импорта тоже заблокировал письмо. Старые контакты, не связанные со сборщиком, сохраняют существующие правила Quickly.

**Согласия и отказы** содержит реестр. Отказ снимает будущие задания этому адресу во всех кампаниях. Повторное автоматическое подтверждение отказавшегося адреса запрещено. Штатная отписка Quickly тоже обновляет статус собранного контакта и историю.

Удаление email из карточки удаляет его из базы компаний, согласий и контактов Quickly, отменяет содержащие его сырые задания. Сохраняется только хеш запрета повторного использования. Серверные почтовые архивы и уже созданные резервные копии отдельно управляются пользователем. Остальные компании и аккаунты не удаляются.

## Отчёты, копии и ограничения

На вкладке **Отчёты** задайте получателя, подключённый SMTP-ящик и по желанию CSV. Функция по умолчанию выключена. Отправка подчиняется аварийной остановке, лимитам и реестру операций Quickly; неопределённая отправка после сбоя автоматически не повторяется.

Все таблицы входят в штатный PostgreSQL-дамп: **Настройки → Резервные копии**. Созданные перед разработкой копии лежат в `~/Library/Application Support/Quickly/backups/quickly-pre-collector-20261026.qbk` и `quickly-pre-collector-20261028.qbk`, права файлов `0600`. Старые копии и ключ шифрования не удаляйте.

Сайты с JS-рендерингом, CAPTCHA, запретами robots.txt/403, ограничениями 429 и недоступными контактами не обходятся. Повторы временных ошибок ограничены тремя попытками с задержкой. Для синтетического DNS настольного VPN используется проверяемый DoH через фиксированный публичный резолвер; каждый реальный IP и переадресация проверяются, частные сети запрещены. На сайте без опубликованного телефона поле останется пустым.
