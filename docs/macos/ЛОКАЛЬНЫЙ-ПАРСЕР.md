# Локальный парсер в Quickly

Откройте **Сбор компаний → Локальный парсер**. Здесь подключён движок отдельного проекта «Парсер для почт»: Яндекс Карты, 2ГИС, СПАРК и Rusprofile. Копия его исходников и лицензий находится в `integrations/company_parser/`.

## Новый сбор из карт

1. Выберите **Яндекс Карты** или **2ГИС**.
2. Введите тематику: например, `Юридические компании`.
3. Укажите города через точку с запятой: `Тула; Рязань; Калуга`. Пустой список не запускает сбор по всей России.
4. Укажите **общий лимит компаний** — он действует на весь запуск, включая все города, до 10 000 компаний.
5. При необходимости включите поиск публичных email на сайтах компаний. Он начнётся после импорта карточек в Quickly и использует существующую защищённую очередь проверки сайтов.
6. Укажите основание обработки выбранных данных и подтвердите его, затем нажмите **Начать сбор**.

API-ключи Яндекса и 2ГИС для этого режима не нужны. Одновременно выполняется один браузерный сбор. Скорость, тайм-аут задания и показ окна Chrome находятся в **Скорость и браузер**. У 2ГИС можно дополнительно указать коды рубрик. Рубрики не подменяются кодами ОКВЭД.

## Пауза и результаты

В карточке запуска показаны состояние, количество компаний, email и ошибки по заданиям. **Пауза** сохраняет полученные данные; **Продолжить** использует тот же план и контрольные точки. Завершение паузы может занять несколько секунд.

После завершения, ошибки или паузы полученные компании автоматически импортируются в базу Quickly. Это работает и после закрытия страницы. Кнопка **Результаты в Quickly** открывает выбранный запуск в общей таблице. Там доступны поиск, карточка компании, происхождение контактов, CSV и Excel. Повторный импорт одной версии не создаёт новый запуск; обновлённая версия сопоставляет уже известные компании и контакты.

Email получают статус согласия **Неизвестно**. Сбор и импорт не создают рассылок и не отправляют писем. Для запусков локального парсера автоматическая отправка отчётов также отключена.

## Старые выгрузки

При подключении программа делает согласованные копии SQLite-баз существующего парсера. В разделе **Запуски и сохранённые выгрузки** они отмечены как старые. Нажмите **Импортировать в Quickly**, укажите основание обработки и подтвердите импорт. Исходные базы остаются на месте и не изменяются. Копии отражают состояние на момент подключения; для обновления списка из отдельного проекта повторите подключение с его путём.

## СПАРК и Rusprofile

Выберите сервис и нажмите **Открыть окно входа**. В отдельном Chrome войдите самостоятельно, выберите фильтры и вставьте HTTPS-ссылку выборки или карточки в Quickly. Пароли и коды вводятся только на сайте сервиса. Не закрывайте отдельное окно до окончания сбора. Сохранённая выборка используется, если ссылки не указаны.

Quickly использует собственные профили Chrome. Авторизованные окна исходного проекта не переносились и не закрывались; для защищённых источников может понадобиться повторный вход. Доступ к контактам зависит от аккаунта, тарифа и ограничений сайта. Проверки доступа и CAPTCHA останавливают сбор; автоматически они не обходятся. Платный доступ к СПАРК/Rusprofile при интеграции не проверялся.

## Установка и хранение

На Mac нужны Python 3.10+ и Google Chrome. Из папки Quickly:

```bash
python3 scripts/setup_local_parser.py
./macos/quickly start
```

Для подключения существующего проекта:

```bash
python3 scripts/setup_local_parser.py --parser-root '/полный/путь/Парсер для почт'
./macos/quickly start
```

Движок, виртуальная среда и копии старых результатов размещаются в `~/Library/Application Support/Quickly/parser-runtime/`. Новые запуски — в `parser-runs/`. Закрытый файл соединения `parser-bridge.json` имеет права 600 и подключается к Docker только для чтения. LaunchAgent `com.quickly.parser-bridge` запускает локальный сервис на `127.0.0.1:8877`. Его API требует секретный токен и запрещает запросы браузерных страниц. Токен не передаётся frontend. HTTP API парсера доступно только через авторизованный backend Quickly.

Исходный проект, его профили и выгрузки сохраняются. Профили, базы, токены и результаты не включаются в Git. Их резервное копирование выполняется отдельно: стандартный бэкап базы Quickly не включает рабочие папки Chrome и парсера. Импортированные в Quickly компании входят в бэкап основной базы.

## Проверка интеграции на Mac, 28.10.2026

- До изменений сохранены дамп PostgreSQL и существующие секреты в закрытой папке резервных копий.
- Локальный сервис доступен из Docker; после установки работает через LaunchAgent, без терминала.
- Отображаются 17 старых запусков, каталоги 986 городов Яндекса и 154 проектов 2ГИС.
- Через интерфейс Яндекс Карт собрано 2 компании с общим лимитом на два города.
- Запуск 2ГИС поставлен на паузу и продолжен; собрано 2 компании и 2 email.
- Оба запуска автоматически появились в общей базе; повторный импорт не увеличил количество компаний и заданий.
- Сохранены источники контактов и статус согласия «Неизвестно».
- 50 почтовых аккаунтов сохранены; контактов для рассылок по-прежнему 0; журнал операций отправки не увеличился (2); аварийная остановка включена.
- Проверены в автоматических тестах ограничения входных данных и адресов, токен соединения, запрет browser-origin, чтение SQLite/WAL без изменений, идемпотентность импорта, происхождение email, экспорт, общий лимит, пауза и продолжение, отсутствие отправки отчётов.

Яндекс Карты и 2ГИС предоставляют доступную выдачу, а не полный реестр организаций. Полнота результатов зависит от выдачи, города, выбранного лимита и доступности сайтов. Отсутствие email в карточке не считается ошибкой.
