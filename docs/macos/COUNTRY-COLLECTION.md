# Поиск почт по областям, городам и странам

В «Сбор компаний → Новый сбор» выберите источник карт и страну.
В «Масштаб поиска → По областям / регионам» отметьте нужные регионы галочками.
Например, «Свердловская область» включает Екатеринбург, Нижний Тагил,
Каменск-Уральский и другие населённые пункты, доступные выбранному источнику.
Поле «Найти область / регион» фильтрует список. Можно выбрать до 30 регионов.
Под списком виден размер плана и примеры населённых пунктов.
Города другой области в этот план не добавляются. В истории сохраняются выбранные
регионы и прогресс обхода; карточки сохраняют регион, если его не указал сам источник.

Яндекс Карты обходят населённые пункты регионов из GeoNames.
2ГИС использует только свои города / проекты с однозначной привязкой к региону;
неоднозначные названия исключаются. Число пунктов и ограничения покрытия видны
до запуска. Наличие нескольких проектов 2ГИС не означает полного покрытия области.

Для всей страны выберите «Масштаб поиска → Вся страна».
Укажите тематику, например «строительные компании». Программа сама составит план
обхода населённых пунктов выбранной страны, привяжет поиск к их координатам и стране.

Для отдельных городов выберите «Масштаб поиска → По отдельным городам».
Список городов с галочками показывается сразу: отметьте один или несколько.
Поле «Найти город» ищет по всему каталогу выбранной страны. Поиск не снимает
уже поставленные галочки; выбранные города также видны над полем поиска.
Для Яндекс Карт доступен ручной ввод: введите название и нажмите
«Добавить введённый город» / Enter. Для 2ГИС выбираются города его каталога.
Можно добавить до 30 городов и убрать ненужные галочкой или крестиком рядом
с названием. Пробелы, например в названии «Нижний Новгород», сохраняются.
При ошибке каталога доступна кнопка повторной загрузки.

Можно ввести «Собери почты строительных компаний по всему Узбекистану» в поле
«Или задайте запрос одной строкой» и нажать «Заполнить параметры». Это заполняет
форму. Проверьте страну и тематику, укажите основание обработки, затем запустите поиск.
Если страна не распознана однозначно, выберите её в списке.

«Сколько карточек проверить» — общий предел за запуск, максимум 10 000.
Достижение предела отмечается отдельно и не считается полным обходом страны.
История показывает количество запланированных, посещённых и полностью проверенных
населённых пунктов, а также ошибки отдельных городов. Пауза сохраняет план и прогресс.
После капчи или требования входа пользователь завершает проверку в браузере сам.

Для Яндекс Карт используется мировой каталог [GeoNames](https://www.geonames.org/export/)
под лицензией CC BY 4.0: населённые пункты от 500 жителей и административные центры.
Для 2ГИС используются города, имеющиеся в каталоге самого источника. Если выбранная
страна там отсутствует, запуск блокируется с понятным сообщением.
Выдача карт и наличие опубликованных email ограничивают фактический результат;
программа не заявляет, что найдены все организации страны.

Почты ищутся в карточках и на сайтах. Результаты без email не попадают в основную
базу результатов; повторные контакты проходят существующую проверку дублей.
Сам сбор писем не отправляет.

Мировой каталог хранится локально в `parser-runtime/data/world-geography.sqlite`.
Области привязаны по административным кодам первого уровня GeoNames (admin1),
а не по совпадению части адреса. Русские названия регионов России поставляются
в `data/region-names-ru.json`; названия других регионов берутся из admin1CodesASCII.
При обновлении старый кеш заменяется только после успешного построения нового.
Новая установка загружает его с официального сервера GeoNames; до успешной установки
зарубежный/общенациональный сбор выдаёт ошибку вместо подстановки России.
