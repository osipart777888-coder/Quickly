# Проверки установленного Quickly

Обновлено 21 октября 2026, Москва. Ветка: `codex/macos-local-ru`.
Подробности последнего аудита: [AUDIT-2026-10-21.md](AUDIT-2026-10-21.md).

## Установка

macOS 26, Apple Silicon arm64, 16 ГБ RAM. Docker Desktop установлен с официального
сайта, проверены подпись приложения и архив установщика. Проект Compose —
`quickly-mac`, образ — `quickly-mac:local`, PostgreSQL 15, отдельный том и сеть.
Приложение опубликовано только на 127.0.0.1:8765; PostgreSQL не публикует порт на Mac.

Quickly.app собран и проверен codesign, LaunchAgent прошёл plutil. Устранён
подтверждённый отказ доступа к Documents: файлы запуска находятся в Application
Support. Новый LaunchAgent реально выполнен в текущей сессии, завершился с кодом 0.
Физическая перезагрузка Mac не выполнялась. Конфигурации других приложений не менялись.

Ключи находятся вне Git/БД в каталоге с правами 0700 и файлах 0600; сохранены в Keychain.
В SQL нет открытых непустых секретных настроек и внешних JWT/Fernet-ключей.
Телеметрия и необязательная внешняя лента отключены. Кампании не разрешены.

## Автоматические проверки

- Полный PostgreSQL-набор: **578 passed**, 263,38 секунды.
- Полный SQLite-набор: **569 passed, 9 skipped**. PostgreSQL-сценарии дополнительно
  выполнены на настоящем PostgreSQL, а не засчитаны по SQLite.
- Node: **2 passed**, русификация не переписывает пользовательские значения,
  переменные персонализации, API-пути и данные форм.
- Сборки frontend и Docker успешны.
- Локальные SMTP/IMAP-тесты используют loopback. Проверены авторизация, отправка,
  получение и явно помеченный диагностический ответ, поиск и папки.
- CSV/XLSX: русские заголовки, дубликаты, сохранение отписок, разрешения, разделение
  отправителей и получателей, отсутствие паролей в сообщениях об ошибках.
- Очереди: STOP, пауза/возобновление, отмена с историей, ограничения отправки,
  отсутствие слепого повтора после неизвестного результата.
- Группы: смена адресатов, отсутствие отправки себе, исключения, лимиты, ответы,
  открытые временные окна после закрытых групп, редактирование без обнуления квот.
- Общий интервал отправителя, UTC при TZ=Europe/Moscow, московские суточные счётчики.
- Подтверждённый отказ авторизации → исправление → явное возобновление → одна новая
  попытка. Принятые, зарезервированные и неопределённые операции не освобождаются.
- Read-only API-ключ: чтение разрешено, изменение настроек возвращает 403.
  Одиннадцатая неверная попытка входа за минуту возвращает 429 даже с разными
  X-Forwarded-For. Новые HTTP/фоновые задачи блокируются на время восстановления.
- Проверки входящих, классификации ответов, отписок, жалоб, отказов, DNS через VPN,
  SSRF и адаптера Postmaster входят в полный набор.

## PostgreSQL: конкуренция и масштаб

Все эксперименты ниже выполнены в отдельных временных базах с синтетическими данными.
Внешних сообщений нет: транспорт имитирован.

- 18 параллельных обработчиков при дневном пределе 5: ровно 5 вызовов транспорта.
- 12 параллельных обработчиков одного ключа задания: ровно один вызов.
- 1000 участников и конкурирующая постановка: ровно 1000 заданий.
- 52 конкурентных обработки при общем пределе 7: ровно 7 отправок. Журнал,
  групповой счётчик и сумма счётчиков ящиков равны 7.
- 30 конкурентных запросов одного отправителя при интервале: ровно один вызов.
- 10 000 контактов импортированы примерно за 0,42 секунды; предпросмотр 1000 пар
  занял около 0,021 секунды, постановка очереди — около 0,091 секунды.

Эти значения измерены на синтетической базе этого Mac. Они не измеряют сетевую
пропускную способность 1000 реальных почтовых аккаунтов.

## Восстановление

- Оборванный dump отклонён, прежняя строка в целевой базе сохранена.
- Неверный внешний ключ отклонён до замены рабочей базы.
- Успешно восстановлены 1000 ящиков и 10 000 контактов; предыдущий dump сохранён.
- Настоящая ошибка DDL при замене откатила всю транзакцию, прежний пользователь сохранён.
- После восстановления STOP=true, campaigns_enabled=false, все расписания на паузе.
- Дополнительная подготовка кандидата из macOS-оболочки выполнена в тестовом контейнере:
  ключ и миграции проверены, ранее включённые расписания остановлены, очередь 1000 сохранена.
- Рабочий pg_dump проверен восстановлением в отдельную базу. Копии находятся вне Git
  в `~/Library/Application Support/Quickly/backups/`. Внешний ключ хранится отдельно.
- При установке 20 октября проверено переключение базы оболочкой с сохранением прежней
  базы `quickly_before_restore_20261020_161810_23744`; она не удалена.

## Браузер и рабочая установка

В отдельном localhost:8766, без планировщика и с отключённым транспортом, выполнен
вход, открыта группа из 1000 аккаунтов, лимит группы изменён 1000 → 2000, лимит
исходных проверок одного ящика 1 → 2. После сохранения группа приостановлена,
очередь из 1000 заданий сохранилась. Рабочая база для этого не использовалась.

В рабочем localhost:8765 проверены healthcheck, вход администратора и отказ 401
без авторизации. Итог: 1 администратор, 0 ящиков, 0 контактов, 0 кампаний,
0 операций отправки; кампании выключены. Тестовые данные пользователю не оставлены.


Дополнительно в браузере сохранён HTML-этап кампании: жирный текст, {{name}} и
ссылка {{unsubscribe_link}} сохранились в базе. Проверено отсутствие зацикливания
при различиях HTML-сериализации Quill и DOMPurify (например, target у ссылки).

## Зависимости и ограничения

pip check: нет нарушенных требований. pip-audit по requirements.lock: известных
уязвимостей не найдено. npm audit: **2 low, 0 moderate/high/critical**, Quill 2.0.3
и его обёртка. Исправленной версии для
[GHSA-v3m3-f69x-jf25](https://github.com/advisories/GHSA-v3m3-f69x-jf25) нет.
DOMPurify защищает ввод/вывод редактора и отображение HTML; это не исправление
самого пакета. Предупреждения об устаревающих API и размере JS остаются.

У пользователя пока нет ящиков. Живые OAuth-согласия, пароли приложений,
доставка и папки Gmail/Microsoft/Яндекс/Mail.ru не проверены на будущих аккаунтах.
Нужны собственные ящики, разрешённые лимиты и настройка DNS. Принятие SMTP/API
не подтверждает конечную доставку и папку. Публичные HTTPS-ссылки и webhooks
не развёрнуты; локальные входящие опрашиваются.
