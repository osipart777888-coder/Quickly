## Ограничения проверки

Платные API проверены на документированных фикстурах; для реального прогона нужны ключи и договорные права. СПАРК требует WSDL и описание разрешённых методов. ФНС поддержана импортом файлов, автоматическая загрузка реестров не реализована. Динамические JS-сайты и закрытые страницы не обходятся. Реальная внешняя пробная отправка не выполнялась; проверки SMTP используют существующие локальные тестовые двойники.
