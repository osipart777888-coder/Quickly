# Quickly на Mac

Откройте **~/Applications/Quickly.app → Открыть Quickly**.
Интерфейс: **http://localhost:8765**. Логин **admin**; пароль — в пункте **Данные входа** оболочки.

Для автоматических проверок 100–500 собственных ящиков откройте **Прогрев и диагностика**:
выберите аккаунты, посмотрите распределение, сохраните группу и включите её расписание.

Ветка `codex/macos-local-ru`. Почтовые ящики добавляются позже; без явного разрешения
кампании не отправляются. Listmonk использует отдельные процессы и не изменялся.
