# Парсер опубликованных почт компаний — Яндекс Карты и 2ГИС

Работают **Яндекс Карты и 2ГИС**: поиск по сфере и городам, чтение карточек, поиск email на указанных сайтах, сохранение источников и выгрузка Excel/CSV. Профиль по умолчанию — юридические компании. **СПАРК и Rusprofile подготовлены к подключению учётных записей; платные кабинеты пока не проверены.**

На этом Mac установлена рабочая среда `.venv`. Нужны Google Chrome и интернет. Подписка на СПАРК или Rusprofile для Яндекса не требуется. При переносе программы сначала откройте **Установить.command**; поддерживается Python 3.10–3.13.

## СПАРК — подготовка к подключению доступа

Запуск — **СПАРК.command**, либо **Запустить.command → 3 (СПАРК)**. Сначала выберите «Вход и выборка», войдите в отдельном Chrome и откройте сохранённый список компаний с нужными фильтрами. Для юридических услуг используйте ОКВЭД 69.10. После этого доступны сбор, продолжение и проверка контактов. Подробности — [SPARK_README.md](SPARK_README.md).

Браузер и вкладка сохраняются между запусками сборщика; поля пароля/кода не читаются. Закрытые контакты помечаются отдельно и перечитываются после входа. Есть резервный импорт официальной выгрузки CSV/XLSX. **Платный кабинет без пользовательского входа не проверен:** после получения доступа обязателен контрольный сбор; если интерфейс отличается от поддержанных страниц, может понадобиться адаптация. Открытые страницы, сохранение сессии, переход «Показать ещё» и обработка маскированных контактов проверены.

## Rusprofile — подготовка к подключению доступа

Запуск — **Rusprofile.command**, либо **Запустить.command → 4 (Rusprofile)**. Есть отдельный вход, сохранение поиска по сфере/региону, проверка контактов, сбор и продолжение, поиск почт на сайтах компаний и Excel/CSV. Для юридических услуг выберите ОКВЭД 69.10 в фильтрах сайта и сохраните поиск. Инструкция — [RUSPROFILE_README.md](RUSPROFILE_README.md).

**Проверка 28 октября: публичная страница вернула 403 Forbidden.** Программа остановилась с `needs_auth`, сохранила очередь и отчёт, не создала фиктивных компаний. Сохранение браузера/вкладки между процессами проверено. Чтение реальных карточек и платного кабинета пока не подтверждено; после входа нужен контрольный сбор, возможна адаптация интерфейса. Скрытые поля помечаются отдельно и перечитываются после входа. Импорт официальной выгрузки доступен отдельным действием.

## 2ГИС — добавлено 28 октября 2026 года

Запуск — **2ГИС.command**, либо **Запустить.command → 1 (2ГИС)**. Доступны новый сбор, продолжение последнего, поиск почт на сайтах, результаты и браузер для ручной проверки доступа. По умолчанию используется точная рубрика «Юридические услуги» (344); можно ввести другую рубрику или свободный запрос.

Очередь карточек и номер следующей страницы сохраняются после каждой операции; при продолжении полученные карточки не открываются заново. Для глубоких страниц используется обычная навигация по кнопкам сайта. Пустые/повторные страницы, недоступные карточки и проверки доступа отражаются отдельно.

Каталог содержит 154 проекта 2ГИС из upstream (снимок 2024 года). Проект может включать соседние города: например, «Москва» включает пригороды. В результатах указывается фактический город карточки. Это не полный реестр всех населённых пунктов страны. Для Яндекса сохраняется отдельная география GeoNames.

Подробная инструкция и реальные проверки 2ГИС — [2GIS_VERIFICATION.md](2GIS_VERIFICATION.md). Пример результатов: `runs/2gis-acceptance-2026-10-28/export/contacts.xlsx`.

```bash
.venv/bin/python -m company_emails collect --source 2gis --city Москва --rubric 344 --max-records 100 --workdir runs/my-2gis --enrich
.venv/bin/python -m company_emails collect --source 2gis --workdir runs/my-2gis --resume-plan --retry-failed --enrich
.venv/bin/python -m company_emails cities --source 2gis
.venv/bin/python -m company_emails rubrics адвокат
```

Без `--city` обрабатывается весь каталог проектов России. `--query` задаёт свободный запрос, `--rubric` — точную категорию. По умолчанию CLI использует две юридические рубрики: юридические услуги и услуги адвоката. В отдельном меню по умолчанию выбрана одна рубрика «Юридические услуги».

## Яндекс Карты — запуск

Дважды нажмите **Яндекс Карты.command**. В общем **Запустить.command** выбор Яндекса открывает то же меню.

1. **Новый сбор** — введите сферу, города и предел карточек на одну пару «город × запрос». Enter оставляет «Юридические компании», весь каталог России и 100 карточек соответственно. Несколько запросов разделяются точкой с запятой, например `Юридические компании;Услуги адвоката`; города — запятыми.
2. **Продолжить последний сбор** — продолжает точный сохранённый план. Пропускает готовые карточки, повторяет незавершённые задания и завершает поиск email на сайтах.
3. **Дополнить почты с сайтов** — проверяет сайты уже собранных компаний; успешные проверки кешируются на 7 дней, неудачные повторяются.
4. **Открыть последние результаты** — открывает папку с Excel/CSV.
5. **Открыть браузер для проверки доступа** — если Яндекс попросил ручную проверку. Выполните её в открывшемся отдельном Chrome, вернитесь в терминал, нажмите Enter, затем выберите продолжение.

**Ctrl+C** останавливает сбор и выгружает полученные контакты. Закрытие терминала/SIGTERM также запускает сохранение; при принудительном выключении следующий запуск восстанавливает законченные записи JSONL. Для продолжения выбирайте действие 2. Новый сбор создаёт отдельную папку и отдельную очередь. Последний запуск Яндекса и 2ГИС запоминается отдельно.

Программа прокручивает выдачу, сохраняет очередь ссылок, затем читает карточки. После каждого задания ищет почты на сайтах компаний и обновляет Excel. Поэтому почты появляются по мере обработки городов. Сбор по всей стране может занять длительное время; компьютер должен оставаться включённым и не спать.

## Что получается

Папка конкретного запуска показывается в терминале: `runs/yandex-ДАТА-ВРЕМЯ/export/`.

- **contacts.xlsx**: «Компании», «Уникальные email», «Задания», «Проверка сайтов».
- **companies.csv**: компании, город, адрес, фактические категории, поисковый запрос, телефоны, сайты, email и исходная карточка.
- **emails.csv**: уникальные почты со связанными компаниями и URL, на которых найден адрес.
- **tasks.csv**, **sites.csv**: ход заданий, лимиты, причины остановки, проверенные страницы и ошибки сайтов. Ещё не проверенные сайты тоже видны.
- **summary.json**: итоговые счётчики.

Компания без email остаётся в таблице. Повторные карточки удаляются по ID Яндекса, филиалы сохраняются отдельно; общая почта сети выводится один раз в списке уникальных email. Телефон берётся из доступного текста карточки. Источником почты служит конкретная публичная страница; адреса не угадываются и не проверяются отправкой письма. Примеры адресов из шаблонов сайтов отфильтровываются.

**Заданный предел не означает полноту города.** `limited` — достигнут предел; `done` — закончился доступный список выдачи; `partial`, `error`, `timeout`, `interrupted` — сбор неполный; `needs_auth` — нужна ручная проверка доступа; `empty` — явно пустая выдача. Состояние сайтов учитывается отдельно: завершённый сбор карточек может содержать недоступные сайты. Причины видны в Excel.

## География и ограничения

Каталог Яндекса содержит **986 населённых пунктов России** с координатами из GeoNames, получен 27 октября 2026 года: население более 15 000 или административные центры, кварталы исключены. Это не список всех населённых пунктов. Маленькие города/посёлки можно ввести вручную, при необходимости вместе с областью; для одноимённых городов доступен точный внутренний код. Происхождение и лицензия данных — в [data/README.md](data/README.md).

Поиск использует публичную выдачу Яндекса, которая меняется и может возвращать организации с несколькими видами деятельности или соседними адресами. В таблице сохраняются реальные категории и город карточки. Поисковый запрос не подменяет категорию организации.

Сайты обходятся по HTTPS: до 4 страниц, с приоритетом контактов и реквизитов, с учётом robots.txt. Ошибки соединения, HTTP 403/429 и недоступный robots.txt отражаются в отчёте. Сайты без рабочего HTTPS, PDF и контакты, появляющиеся только после выполнения JavaScript, могут остаться непроверенными. Наличие опубликованного email не гарантирует доставку письма. При ответе Яндекса HTTP 429/`limited` программа также сохраняет очередь и останавливается: подождите перед продолжением. Проверки доступа автоматически не обходятся.

Используется отдельный профиль Chrome `.local/profiles/yandex`; обычный профиль пользователя не читается. Одновременный запуск одного профиля блокируется. После аварии удаляется блокировка умершего процесса и закрывается только оставшийся браузер с тем же выделенным профилем и портом отладки. `.local/` и `runs/` исключены из Git.

## Проверено 27 октября 2026 года

Реальный сбор: **120 карточек** (Тула, Рязань, Калуга, по 40), **45 уникальных почт у 37 компаний**, 75 сайтов. В 120 карточках присутствовала категория «Юридические услуги». Состояния сайтов: 45 без ошибок, 7 частично проверены, 23 недоступны/пропущены с объяснением.

Сбор намеренно прерван после 5 сохранённых компаний: Excel создан, затем продолжение восстановило эти карточки и дочитало оставшиеся 35 в первом городе. Повторный запуск готового плана не открывал карточки повторно. Дополнительно проверены поиск с координатами Подольска и новый запуск через меню для Тулы/Калуги с поиском почт после каждого города. **48 автоматических проверок проходят.** Подробности — [YANDEX_VERIFICATION.md](YANDEX_VERIFICATION.md), готовая выборка — `runs/yandex-acceptance-2026-10-27/export/contacts.xlsx`.

Эта проверка подтверждает работу сценария на указанных выборках. Массовый проход по всем 986 пунктам ещё не выполнялся; он запускается через меню. Полный реестр всех компаний России публичная выдача карт не предоставляет.

## Командная строка

Из папки проекта:

```bash
# Показать очередь без сбора
.venv/bin/python -m company_emails plan --source yandex --query "Юридические компании"

# По 100 карточек в каждом пункте каталога + сайты
.venv/bin/python -m company_emails collect --source yandex --query "Юридические компании" --max-records 100 --workdir runs/my-yandex --enrich

# Конкретные города; --city и --query можно повторять
.venv/bin/python -m company_emails collect --source yandex --query "Юридические компании" --city Тула --city Калуга --max-records 40 --workdir runs/my-cities --enrich

# Продолжить неизменный план; не добавляйте новые города/запросы
.venv/bin/python -m company_emails collect --source yandex --workdir runs/my-yandex --resume-plan --retry-failed --enrich

# Только сайты, текущий статус, повторная выгрузка
.venv/bin/python -m company_emails enrich --source yandex --workdir runs/my-yandex
.venv/bin/python -m company_emails status --source yandex --workdir runs/my-yandex
.venv/bin/python -m company_emails export --source yandex --workdir runs/my-yandex

# Найти код города
.venv/bin/python -m company_emails cities --source yandex Тула

# Проверки без интернета
.venv/bin/python -m pytest -q tests
```

Опции: `--visible` показывает Chrome во время сбора; `--timeout 900` ограничивает одно задание; `--delay 1` задаёт интервал между карточками (минимум 0.5 с); `--max-pages 4` ограничивает страницы одного сайта; `--site-limit 20` ограничивает число сайтов за запуск; `enrich --refresh` повторяет успешные проверки. `--cities-file` принимает собственный каталог; формат описан в `data/README.md`. База SQLite сохраняет контакты сразу, JSONL и журналы остаются в `jobs/<ID>/`.
